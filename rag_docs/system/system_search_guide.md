# Руководство по модулю поиска лидов

## 📋 Назначение документа
Этот документ объясняет, как использовать модуль поиска потенциальных клиентов: настройка фильтров, интерпретация результатов, работа со скорингом и запуск углублённой аналитики.

---

## 🔍 Как работает поиск

### Источники данных
Поиск выполняется по открытым источникам интернета:
- Сайты компаний (разделы «О нас», «Контакты», «Проекты»)
- Отраслевые каталоги (АВОК, SRO-реестры, профильные порталы)
- Реестры госзакупок (упоминания в 44-ФЗ/223-ФЗ)
- Новости и публикации в отраслевых СМИ

> **Важно:** Платные закрытые источники (СПАРК, Контур.Фокус) не используются в MVP.

### Алгоритм обработки
1. Парсинг → извлечение текста с сайтов по заданным критериям
2. Фильтрация → исключение «мусора» по правилам (ОКВЭД, оборот, срок регистрации)
3. Структурирование → преобразование в JSON по шаблону LeadRawSchema
4. Квалификация → скоринг 0–100 по правилам из sales_objections.md
5. Обогащение (по запросу) → углублённый анализ по компании

## ⚙️ Настройка фильтров поиска

### Обязательные фильтры
| Фильтр | Значения | Пример |
|--------|----------|--------|
| Регион | Субъекты РФ, города | `Самарская область`, `Екатеринбург` |
| ОКВЭД | Коды видов деятельности | `43.22` (монтаж инженерных систем), `71.12` (проектирование) |
| Мин. оборот | Порог в млн ₽/год | `50` (исключает ИП и мелкие ООО) |
| Признаки активности | Чекбоксы | `Есть сайт`, `Обновления новостей`, `Вакансии` |

### Дополнительные фильтры (расширенный режим)
| Фильтр | Значения | Когда использовать |
|--------|----------|-------------------|
| Исключить ОКВЭД | Коды для исключения | `47.19` (розница), `85.11` (образование) |
| Срок регистрации | Мин. возраст компании | Исключить компании <6 месяцев |
| Участие в тендерах | Да/Нет/Неважно | Поиск компаний с опытом госзакупок |
| Наличие ЛПР | Определён/Не определён | Приоритет лидов с контактами |

### Как сохранить шаблон поиска
1. Настройте фильтры под задачу
2. Нажмите «Сохранить как шаблон»
3. Укажите имя: например, «Монтажники Поволжья»
4. Шаблон появится в списке «Мои шаблоны» для быстрого запуска

## 📊 Интерпретация результатов поиска

### Таблица результатов: поля и значения
| Поле | Описание | Как использовать |
|------|----------|-----------------|
| Название | Юридическое наименование компании | Для идентификации, проверки по ИНН |
| ИНН | Идентификатор налогоплательщика | Для проверки контрагента в реестрах |
| Регион | География регистрации/деятельности | Для сопоставления с зоной покрытия |
| Сайт | Ссылка на сайт компании | Для ручной проверки, сбора контактов |
| Скоринг | Оценка 0–100 по целевому потенциалу | Фильтрация: ≥80 — горячие, 50–79 — тёплые, <50 — холодные |
| Статус | `hot` / `warm` / `cold` / `disqualified` | Быстрая визуальная сортировка |
| Источник | Откуда найдена компания | Для оценки надёжности данных |

### Как читать скоринг (0–100)
Скоринг рассчитывается по правилам из `sales_objections.md` и `segment_*.md`:

| Баллы | Статус | Интерпретация | Рекомендация |
|-------|--------|---------------|--------------|
| 80–100 | `hot` | Высокий потенциал: совпадение по ОКВЭД, обороту, признакам активности, наличие ЛПР | Передать менеджеру в приоритетном порядке |
| 50–79 | `warm` | Средний потенциал: есть совпадения, но не все критерии закрыты | Запустить углублённую аналитику, передать после проверки |
| 30–49 | `cold` | Низкий потенциал: частичное совпадение, требуются уточнения | Отложить в резерв, не тратить время на холодный контакт |
| 0–29 | `disqualified` | Нецелевой: розница, физлица, ликвидация, несоответствие профилю | Исключить из выдачи, добавить в чёрный список |

> **Примечание:** Скоринг — рекомендательный. РОП может вручную изменить статус лида.

## 🔬 Углублённая аналитика по компании

### Как запустить
1. В таблице результатов выберите компанию (чекбокс)
2. Нажмите кнопку «Аналитика»
3. Система соберёт данные из открытых источников за 10–30 секунд

### Что отображается в карточке аналитики
| Блок | Содержание | Источник данных |
|------|-----------|----------------|
| Финансовые признаки | Признаки активности: сайт, вакансии, новости | Парсинг сайта, реестры |
| Тендерная активность | Участие в 44-ФЗ/223-ФЗ за 12 месяцев | Реестры госзакупок |
| Техническая совместимость | Профиль деятельности, наличие СРО, география проектов | Сайт, отраслевые реестры |
| Контакты и ЛПР | Предполагаемые лица, принимающие решения | Раздел «Команда», соцсети, новости |
| Риски | Признаки ликвидации, задолженности, судебных дел | Открытые реестры (ФНС, ФССП) |

### Как использовать аналитику
- **Для квалификации:** Сравните признаки с профилем идеального клиента из `segment_*.md`
- **Для подготовки звонка:** Используйте блок «Контакты и ЛПР» для персонализации обращения
- **Для аргументации:** Блок «Тендерная активность» помогает понять опыт работы с госзаказом

## 📤 Экспорт и передача лидов

### Форматы экспорта
| Формат | Когда использовать | Поля в файле |
|--------|-------------------|-------------|
| CSV | Для импорта в таблицы, простую аналитику | Название, ИНН, регион, сайт, скоринг, статус, источник |
| Excel (.xlsx) | Для передачи менеджерам, печати | Те же поля + форматирование, фильтры, сортировка |
| JSON | Для интеграции с внешними системами (пост-MVP) | Полная структура лида, включая аналитику |

### Как передать лиды в работу
1. Отметьте нужные компании в таблице результатов
2. Нажмите «Экспорт» → выберите формат
3. Сохраните файл или отправьте на почту
4. Вручную загрузите в рабочую таблицу менеджеров или CRM (пост-MVP)

> **Важно для MVP:** Автоматическая синхронизация с Битрикс24/1С не реализована. Передача — вручную через экспорт.

## ❓ Частые вопросы по поиску

**В: Почему компания не попала в выдачу, хотя подходит по ОКВЭД?**  
О: Возможные причины: 1) Исключена по другим фильтрам (оборот, срок регистрации); 2) Сайт не проиндексирован или недоступен; 3) Компания уже есть в базе НЕВАТОМ (проверка по ИНН). Проверьте настройки фильтров.

**В: Как повысить точность поиска?**  
О: Используйте комбинацию фильтров: ОКВЭД + регион + признаки активности. Сохраняйте удачные шаблоны. Запускайте углублённую аналитику для пограничных случаев (скоринг 50–79).

**В: Можно ли искать по названию продукции?**  
О: В MVP — только по ОКВЭД и текстовому описанию деятельности. Поиск по ключевым словам в контенте сайта — пост-MVP.

**В: Как обновить результаты поиска?**  
О: Нажмите «Обновить» — система перезапустит парсинг по тем же фильтрам. Данные кэшируются на 24 часа для оптимизации нагрузки.

**В: Кто может запускать поиск?**  
О: РОП — полный доступ (настройка фильтров, аналитика, экспорт). Менеджер — только просмотр назначенных лидов и экспорт своих списков.
