# Руководство по аналитике и отчётности

## 📋 Назначение документа
Этот документ объясняет, как читать дашборд, интерпретировать метрики, строить отчёты и использовать данные для оптимизации работы отдела продаж.

---

## 📈 Дашборд: основные виджеты

### Виджет 1: Статистика поиска
| Метрика | Описание | Как использовать |
|---------|----------|-----------------|
| Всего найдено | Количество компаний в выдаче за период | Оценка охвата, корректировка фильтров |
| Целевые (%) | Доля лидов со скорингом ≥50 | Точность поиска: цель ≥85% |
| Горячие лиды | Количество со скорингом ≥80 | Приоритет для передачи менеджерам |
| Исключено | Количество отфильтрованных «мусорных» компаний | Оценка качества правил фильтрации |

### Виджет 2: Конверсия по этапам
| Этап | Метрика | Цель |
|------|---------|------|
| Поиск → Квалификация | % лидов, по которым запущена аналитика | ≥30% (интерес к углублённому анализу) |
| Квалификация → Передача | % лидов, переданных менеджерам | ≥50% от горячих (скоринг ≥80) |
| Передача → Контакт | % лидов, по которым был первый звонок | ≥70% (качество подготовки списка) |
| Контакт → Следующий шаг | % диалогов с фиксацией действия | ≥40% (эффективность квалификации) |

### Виджет 3: Распределение по сегментам
| Сегмент | Доля в выдаче | Конверсия в передачу |
|---------|--------------|---------------------|
| Монтажники | 45% | 55% |
| Проектировщики | 25% | 40% |
| Генподрядчики | 20% | 65% |
| Промпредприятия | 10% | 70% |

> **Как использовать:** Если сегмент имеет высокую долю, но низкую конверсию — пересмотрите критерии поиска или скрипты для этого сегмента (`segment_*.md`).

### Виджет 4: Топ источников
| Источник | Доля лидов | Конверсия в горячие |
|----------|-----------|---------------------|
| Сайты компаний | 60% | 35% |
| Отраслевые каталоги | 25% | 50% |
| Реестры госзакупок | 15% | 70% |

> **Как использовать:** Источники с высокой конверсией — приоритет для расширения парсинга. Низкая конверсия — проверить качество данных или скорректировать фильтры.

## 📊 Как строить отчёты

### Отчёт 1: Еженедельная сводка для РОПа
**Период:** Пн–Вс  
**Содержание:**
1. Всего найдено / целевые / горячие (динамика к прошлой неделе)
2. Конверсия по этапам (поиск → контакт → следующий шаг)
3. Топ-5 компаний по скорингу с краткой аналитикой
4. Рекомендации: какие фильтры скорректировать, какие сегменты усилить

**Как сформировать:**
1. Откройте дашборд → вкладка «Отчёты»
2. Выберите шаблон «Еженедельная сводка»
3. Укажите период → нажмите «Сгенерировать»
4. Экспорт в PDF/Excel или отправка на почту

### Отчёт 2: Анализ эффективности фильтров
**Цель:** Понять, какие фильтры дают наибольшую точность  
**Метрики:**
- Точность по каждому фильтру: % целевых среди отфильтрованных
- Комбинации фильтров: какие наборы дают ≥90% целевых
- Ложные срабатывания: какие компании исключаются ошибочно

**Как использовать:**
1. Откройте «Анализ фильтров» на дашборде
2. Выберите фильтр или комбинацию
3. Система покажет статистику и рекомендации
4. Сохраните удачные комбинации как шаблоны

### Отчёт 3: Сегментный анализ
**Цель:** Оценить качество поиска и подготовки под каждый сегмент  
**Метрики:**
- Доля сегмента в выдаче
- Конверсия в передачу менеджерам
- Средний скоринг по сегменту
- Топ возражений при первом контакте (из `sales_analytics_schema.md`)

**Как использовать:**
1. Откройте «Сегменты» на дашборде
2. Выберите сегмент: монтажники / проектировщики / генподрядчики / промпредприятия
3. Система покажет метрики и сравнение с другими сегментами
4. Экспортируйте рекомендации для адаптации скриптов (`segment_*.md`)

## 🔍 Как интерпретировать метрики

### Скоринг лида (0–100)
| Диапазон | Что означает | Действия |
|----------|-------------|----------|
| 80–100 | Высокий потенциал: совпадение по всем ключевым критериям | Передать менеджеру в приоритете, запустить аналитику |
| 50–79 | Средний потенциал: есть совпадения, но не все критерии закрыты | Запустить аналитику, передать после ручной проверки |
| 30–49 | Низкий потенциал: частичное совпадение | Отложить в резерв, не тратить время на холодный контакт |
| 0–29 | Нецелевой: несоответствие профилю | Исключить, добавить в чёрный список |

> **Важно:** Скоринг — рекомендательный. РОП может вручную изменить статус на основе экспертизы.

### Конверсия по этапам
| Этап | Нормальное значение | Если ниже — проверить |
|------|--------------------|----------------------|
| Поиск → Квалификация | ≥30% | Качество выдачи: возможно, слишком жёсткие фильтры |
| Квалификация → Передача | ≥50% (для горячих) | Процесс проверки: возможно, не хватает аналитики |
| Передача → Контакт | ≥70% | Качество списка: возможно, устаревшие контакты |
| Контакт → Следующий шаг | ≥40% | Эффективность скриптов: возможно, нужна адаптация под сегмент |

### Точность поиска (целевые / всего)
| Значение | Интерпретация | Действия |
|----------|--------------|----------|
| ≥90% | Отлично: фильтры работают точно | Масштабировать на новые регионы/ОКВЭД |
| 80–89% | Хорошо: есть небольшой «шум» | Точечно скорректировать правила исключения |
| 60–79% | Удовлетворительно: много ручной проверки | Пересмотреть критерии фильтрации, добавить источники |
| <60% | Низкая: поиск неэффективен | Срочно перенастроить фильтры, проверить парсинг |

## 📤 Экспорт аналитики

### Форматы
| Формат | Когда использовать | Особенности |
|--------|-------------------|-------------|
| PDF | Для презентаций руководству, печати | Фиксированное форматирование, нельзя редактировать |
| Excel (.xlsx) | Для дальнейшей аналитики, сводных таблиц | Можно фильтровать, сортировать, строить графики |
| CSV | Для импорта в внешние BI-системы | Простой текст, разделитель — запятая |
| JSON | Для интеграции с API (пост-MVP) | Полная структура данных, включая метаданные |

### Как настроить автоматическую отправку отчётов
1. Откройте «Отчёты» → «Расписание»
2. Выберите шаблон отчёта и периодичность (ежедневно / еженедельно / ежемесячно)
3. Укажите получателей (РОП, аналитик, менеджер)
4. Выберите формат (PDF / Excel) и способ доставки (почта / чат)
5. Сохраните расписание

> **Примечание:** В MVP автоматическая отправка доступна только по расписанию. Триггерные отчёты (по событию) — пост-MVP.

## ❓ Частые вопросы по аналитике

**В: Почему конверсия упала на этой неделе?**  
О: Возможные причины: 1) Изменены фильтры поиска; 2) Новый источник данных с низким качеством; 3) Сезонный спад активности компаний. Проверьте виджет «Анализ фильтров» и «Топ источников».

**В: Как сравнить эффективность поиска по разным регионам?**  
О: Откройте «Сегментный анализ» → выберите фильтр «Регион». Система покажет сравнение метрик: точность, конверсия, средний скоринг. Экспортируйте в Excel для детального разбора.

**В: Можно ли экспортировать сырые данные для внешней аналитики?**  
О: Да, в формате JSON или CSV. Откройте «Экспорт» → выберите «Полные данные» → укажите период и фильтры → скачайте файл.

**В: Кто имеет доступ к аналитике?**  
О: РОП — полный доступ (все виджеты, отчёты, экспорт). Менеджер — только свои метрики (конверсия по переданным лидам). Аналитик — доступ на чтение ко всем данным.

**В: Как часто обновляются данные на дашборде?**  
О: Метрики пересчитываются раз в сутки в 03:00 по московскому времени. Кнопка «Обновить вручную» доступна для РОПа.
