# Частые вопросы по работе с системой

## 📋 Назначение документа
Этот документ содержит ответы на типовые вопросы по интерфейсу, ролям, настройкам и устранению неполадок. Используйте его как справочник при работе с веб-приложением.

---

## 🔐 Доступ и роли

### В: Кто может запускать поиск лидов?
**О:** РОП — полный доступ (настройка фильтров, аналитика, экспорт). Менеджер — только просмотр назначенных лидов и экспорт своих списков. Администратор — управление пользователями и настройками системы.

### В: Как добавить нового менеджера в систему?
**О:** Только РОП или администратор:
1. Откройте «Настройки» → «Пользователи»
2. Нажмите «Добавить пользователя»
3. Заполните: ФИО, роль (менеджер/РОП), почту, регион ответственности
4. Система отправит приглашение на почту с инструкцией по входу

### В: Можно ли ограничить менеджеру доступ к определённым регионам?
**О:** Да. При создании/редактировании пользователя укажите «Регионы ответственности». Менеджер будет видеть только лиды из этих регионов.

### В: Что делать, если забыл пароль?
**О:** На странице входа нажмите «Забыли пароль?» → введите почту → получите ссылку для сброса. Ссылка действует 1 час.

## 🔍 Работа с поиском

### В: Почему поиск выдаёт пустой результат?
**О:** Возможные причины:
1. Слишком жёсткие фильтры (попробуйте убрать 1–2 условия)
2. Нет данных по заданным ОКВЭД/региону в открытых источниках
3. Временная ошибка парсинга (попробуйте через 10 минут)
4. Компании уже есть в базе НЕВАТОМ (проверка по ИНН)

**Решение:** Ослабьте фильтры, проверьте логи парсинга, обратитесь к администратору при повторяющихся ошибках.

### В: Как сохранить удачные настройки поиска?
**О:** После настройки фильтров нажмите «Сохранить как шаблон» → укажите имя (например, «Монтажники Поволжья») → шаблон появится в списке «Мои шаблоны» для быстрого запуска.

### В: Можно ли искать по названию продукции (например, «канальные вентиляторы»)?
**О:** В MVP — только по ОКВЭД и текстовому описанию деятельности. Поиск по ключевым словам в контенте сайта — пост-MVP.

### В: Как обновить результаты поиска?
**О:** Нажмите кнопку «Обновить» — система перезапустит парсинг по тем же фильтрам. Данные кэшируются на 24 часа для оптимизации нагрузки.

### В: Почему компания получила низкий скоринг?
**О:** Скоринг рассчитывается по правилам из `sales_objections.md` и `segment_*.md`. Возможные причины:
- Несоответствие ОКВЭД профилю НЕВАТОМ
- Отсутствие признаков активности (сайт, вакансии, новости)
- Низкий оборот или короткий срок регистрации
- Признаки ликвидации/судебных дел

**Решение:** Запустите углублённую аналитику для ручной проверки или скорректируйте правила скоринга через РОПа.

## 📊 Аналитика и отчётность

### В: Как посмотреть конверсию по своим лидам?
**О:** Менеджер: откройте «Мои лиды» → вкладка «Статистика». РОП: дашборд → виджет «Конверсия по этапам» с фильтром по менеджеру.

### В: Можно ли экспортировать аналитику для презентации руководству?
**О:** Да. Откройте «Отчёты» → выберите шаблон (например, «Еженедельная сводка») → укажите период → нажмите «Экспорт в PDF». Форматирование сохранится для печати.

### В: Как часто обновляются данные на дашборде?
**О:** Метрики пересчитываются раз в сутки в 03:00 по московскому времени. Кнопка «Обновить вручную» доступна для РОПа.

### В: Почему в отчёте нет данных за вчера?
**О:** Возможные причины:
1. Не было активности (поиск, передача лидов, звонки)
2. Данные ещё не обработаны (пересчёт в 03:00)
3. Ошибка в логировании (обратитесь к администратору)

## 📤 Экспорт и интеграции

### В: В каких форматах можно экспортировать данные?
**О:** 
- **CSV** — для импорта в таблицы, простую аналитику
- **Excel (.xlsx)** — для передачи менеджерам, печати, сводных таблиц
- **JSON** — для интеграции с внешними системами (пост-MVP)

### В: Можно ли автоматически загружать лиды в Битрикс24?
**О:** В MVP — нет. Передача лидов — вручную через экспорт в CSV/Excel. Автоматическая синхронизация с Битрикс24 через REST API — пост-MVP.

### В: Как отправить экспорт на почту?
**О:** После формирования файла нажмите «Отправить на почту» → укажите получателей → система отправит файл вложением. Лимит: до 10 получателей за раз.

### В: Можно ли настроить автоматический экспорт по расписанию?
**О:** Да, для РОПа: «Отчёты» → «Расписание» → выберите шаблон, периодичность, получателей, формат. Система будет отправлять отчёт автоматически.

## ⚙️ Настройки и устранение неполадок

### В: Как изменить пароль?
**О:** Откройте «Профиль» → «Безопасность» → «Сменить пароль». Требуется ввести текущий пароль и подтвердить новый.

### В: Что делать, если интерфейс не грузится?
**О:** Пошагово:
1. Обновите страницу (Ctrl+F5)
2. Очистите кэш браузера
3. Попробуйте другой браузер (Chrome, Firefox, Edge)
4. Проверьте подключение к интернету
5. Если не помогло — обратитесь к администратору с скриншотом ошибки

### В: Почему не работает кнопка «Аналитика»?
**О:** Возможные причины:
1. Не выбрана компания в таблице (отметьте чекбокс)
2. Превышен лимит запросов (лимит: 50 аналитик в день на пользователя)
3. Временная ошибка сервера (попробуйте через 5 минут)

**Решение:** Проверьте условия, при необходимости обратитесь к администратору.

### В: Как сообщить об ошибке в системе?
**О:** Нажмите на иконку «?» в правом нижнем углу → «Сообщить об ошибке» → опишите проблему, прикрепите скриншот → отправьте. Администратор получит уведомление.

### В: Можно ли отключить уведомления?
**О:** Да. «Профиль» → «Уведомления» → снимите галочки с ненужных типов (новые лиды, статусы, отчёты). Изменения сохраняются автоматически.

## 🤖 Чат-бот виджет

### В: Как переключить режим чат-бота?
**О:** В виджете чата нажмите на вкладку: 
- 🔍 «Поиск лидов» — вопросы по работе с модулем поиска и аналитики
- ❓ «Справка» — вопросы по интерфейсу, ролям, экспорту

### В: Чат-бот не понимает мой вопрос. Что делать?
**О:** Попробуйте:
1. Перефразировать вопрос короче и конкретнее
2. Использовать ключевые слова из меню (например, «скоринг», «экспорт», «фильтры»)
3. Переключить режим чат-бота, если вопрос не по теме текущего

Если не помогло — используйте форму «Сообщить об ошибке» или обратитесь к РОПу.

### В: Может ли чат-бот запустить поиск или аналитику?
**О:** В MVP — нет. Чат-бот отвечает на вопросы и даёт рекомендации, но не выполняет действия. Запуск поиска/аналитики — только через интерфейс.

### В: Где хранится история чата?
**О:** История сохраняется в вашем профиле 30 дней. Для просмотра: откройте чат-бот → нажмите «История». Экспорт истории — пост-MVP.

## 📞 Поддержка

### В: К кому обращаться при технических проблемах?
**О:** 
1. Сначала — чат-бот в режиме «Справка» (быстрые ответы)
2. Затем — форма «Сообщить об ошибке» в интерфейсе
3. При критичных сбоях — администратор системы (контакты в «Профиле» → «Поддержка»)

### В: Как запросить новую функцию?
**О:** «Профиль» → «Предложить улучшение» → опишите идею, обоснуйте пользу → отправьте. РОП рассматривает предложения раз в месяц.

### В: Где найти документацию по обновлению правил фильтрации?
**О:** Внутренняя документация для администраторов доступна по ссылке в «Настройки» → «Документация». Доступ только для роли «Администратор».
