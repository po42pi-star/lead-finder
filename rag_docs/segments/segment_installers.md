# Сегмент: Монтажные организации

## 📋 Профиль сегмента

| Параметр | Значение |
|----------|----------|
| Кто это | Компании, выполняющие монтаж инженерных систем: вентиляция, кондиционирование, дымоудаление |
| Типичный размер | 5–50 человек в штате, оборот 20–200 млн ₽/год |
| ЛПР | Прораб, начальник участка, технический директор, руководитель проекта |
| Процесс закупки | Запрос → КП → согласование с прорабом/ГИПом → заказ → отгрузка → монтаж |
| Цикл сделки | 3–14 дней (короткий, зависит от графика объекта) |
| Ключевой драйвер | Соблюдение графика монтажа, отсутствие простоев бригады |

## 🎯 Боли и потребности (специфичные для сегмента)

### Операционные боли
| Боль | Проявление | Почему важно для монтажников |
|------|-----------|-----------------------------|
| Срыв поставок | Оборудование не приехало к началу смены | Простой бригады = штрафы от генподрядчика + потеря репутации |
| Несоответствие узлов | Вентилятор не подходит к воздуховоду по сечению/фланцу | Переделки на объекте = дополнительные затраты и время |
| Нет техподдержки при подборе | Ошибка в спецификации обнаружена на монтаже | Демонтаж/замена = простой + конфликт с заказчиком |
| Сложная логистика | Длинномеры не разгружаются в стеснённых условиях | Бригада ждёт разгрузки = простой = деньги |

### Коммерческие боли
| Боль | Проявление | Почему важно |
|------|-----------|-------------|
| Непредсказуемая цена | Стоимость меняется между КП и заказом | Сложно держать маржу в смете |
| Отсутствие ЗИП | Нет запчастей для быстрого ремонта | Вызов сервиса = простой объекта |
| Нет гибкости по оплате | Предоплата 100% при кассовых разрывах | Давление на оборотные средства |

### Технические боли
| Боль | Проявление | Почему важно |
|------|-----------|-------------|
| Сложность монтажа | Узлы требуют спец. инструмента или навыков | Увеличение времени на объект = снижение производительности |
| Нет документации на месте | Паспорта, схемы, сертификаты не в комплекте | Задержка приёмки, вопросы технадзора |
| Несовместимость с проектом | Оборудование не проходит по габаритам/характеристикам | Переделка проекта или замена оборудования = время и деньги |

## 💬 Язык коммуникации: что говорить / что не говорить

### ✅ Говорить (триггеры доверия)
| Фраза | Почему работает для монтажников |
|-------|--------------------------------|
| «Отгрузка сегодня при подтверждении до 14:00» | Закрывает боль срыва графика |
| «В наличии на ближайшем складе» | Снижает риск логистических задержек |
| «Совместимость с вашим проектом гарантируем» | Снимает страх переделок на объекте |
| «Простой монтаж: фланцы/ниппели в комплекте» | Экономит время бригады |
| «Инженер на связи в день монтажа» | Подстраховка при непредвиденных ситуациях |
| «Документация в каждом коробе» | Упрощает сдачу технадзору |

### ❌ Не говорить (триггеры отторжения)
| Фраза | Почему отталкивает монтажников |
|-------|-------------------------------|
| «Теоретический расчёт аэродинамики» | Не нужно на объекте, нет времени читать |
| «Сложная интеграция в диспетчеризацию» | Не их зона ответственности, это наладчики |
| «Акция действует при заказе от 1 млн» | Не релевантно для точечных закупок под объект |
| «Срок изготовления 45 дней» | Не вписывается в график монтажа |
| «Требуется спец. инструмент для установки» | Дополнительные затраты и риски |

## ❓ Специфичные квалификационные вопросы (не из общего банка)

> Эти вопросы уникальны для сегмента и не дублируют `sales_questions_bank.md`.

### Вопросы по графику и логистике
1. «По какому графику идёт монтаж на объекте: смена, неделя, этап?»
2. «Есть ли "критический путь" в графике, где задержка поставки остановит всю работу?»
3. «Как организована разгрузка на объекте: есть ли манипулятор, кран, свободный подъезд?»
4. «Кто принимает оборудование на месте: прораб, кладовщик, технадзор?»

### Вопросы по совместимости и монтажу
5. «Работаете по готовому проекту или есть возможность адаптации узлов под наличие?»
6. «Есть ли ограничения по габаритам/весу в месте установки оборудования?»
7. «Используете ли типовые узлы или каждый объект требует индивидуальной проработки?»
8. «Кто на объекте отвечает за проверку соответствия оборудования проекту?»

### Вопросы по процессу согласования
9. «Как быстро согласовывается замена позиции, если исходная не подошла?»

## ⚠️ Типичные возражения монтажников + контекстная отработка

> Формат: возражение → ссылка на универсальную стратегию → специфичный акцент для сегмента.

### Возражение: «Дорого, есть дешевле»
- **Ссылка:** `sales_objections.md` #price_TCO
- **Контекст для монтажников:** Для них «дорого» часто означает «риск маржи», а не «риск бюджета». Перефразируйте: «Понимаю, что маржа важна. Давайте сравним: наше оборудование = отгрузка сегодня = нет простоя бригады. Простой 1 дня = Х рублей убытка. Наша наценка = Y рублей. Выгодно?»

### Возражение: «Нет в наличии, нужно срочно»
- **Ссылка:** `sales_objections.md` #availability_swap
- **Контекст:** Предложите не просто аналог, а аналог «со склада в их регионе» + «с совместимыми узлами». «Есть КВ-315 на складе в Самаре — отгрузка за 2 часа. Фланцы совпадают с вашим проектом, монтаж не изменится. Отправить спецификацию?»

### Возражение: «Сомнения в совместимости с проектом»
- **Ссылка:** `sales_objections.md` #tech_support
- **Контекст:** Акцент на «документация в коробе» и «инженер на связи в день монтажа». «В каждый короб кладём паспорт, схему подключения, сертификат. Инженер на связи по видеосвязи в день монтажа — поможет с узлами. Это исключает переделки. Удобно?»

### Возражение: «Сложная логистика на объект»
- **Ссылка:** `sales_objections.md` #logistics_simplify
- **Контекст:** Предложите «доставку до точки монтажа» и «разгрузку манипулятором». «Доставляем манипулятором до точки установки, разгружаем, прокладываем маршрут. Это снимает логистические риски с вашей бригады. Включить в КП?»

## 🎯 Скрипты закрытия для сегмента (адаптации)

> Ссылки на `sales_closing.md`, специфичные формулировки для монтажников.

### Закрытие на срочную отгрузку
- **Ссылка:** `sales_closing.md` #rush_delivery
- **Адаптация:** «Эта позиция в наличии на складе в Самаре. Если подтвердите заказ до 14:00 — отгрузим сегодня, и вы получите её за 2 дня. Если позже — сдвиг на 3-4 дня. Какой вариант закрывает ваш график монтажа?»

### Закрытие на резервирование позиции
- **Ссылка:** `sales_closing.md` #reserve_slot
- **Адаптация:** «Понимаю, что решение ещё не принято. Но эта модель сейчас в наличии на ближайшем складе. Могу зарезервировать на 3 дня без предоплаты — если решите, отгрузим сразу. Если нет — просто снимем бронь. Удобно для вашего графика?»

### Закрытие на включение в спецификацию
- **Ссылка:** `sales_closing.md` #include_in_spec
- **Адаптация:** «Чтобы наше оборудование было учтено в вашей спецификации, давайте подготовим узлы с нашими параметрами. Инженер сделает это за день. Это не обязывает к закупке, но упростит согласование с прорабом позже. Пришлю черновик на проверку?»

### Закрытие на техподдержку в день монтажа
- **Ссылка:** `sales_closing.md` #tech_support_close
- **Адаптация:** «Чтобы монтаж прошёл без сбоев, закрепляю инженера на день вашей установки. Он на связи по видеосвязи, поможет с узлами. Это бесплатно и снимает риски переделок. Включить в поставку?»

## 📄 Документация и процесс: что требуют монтажники

### Обязательный пакет документов
| Документ | Зачем монтажнику | Формат предоставления |
|----------|-----------------|----------------------|
| Паспорт изделия | Для технадзора и сдачи объекта | В каждом коробе + электронно с ЭЦП |
| Схема подключения/узла | Для быстрого монтажа без ошибок | Печатная вкладка + QR-код на видеоинструкцию |
| Сертификат соответствия | Для прохождения экспертизы | Электронно с ЭЦП, при необходимости — заверенная копия |
| Спецификация с артикулами | Для сверки при приёмке | В КП и в коробе |

### Процесс взаимодействия (типичный)

1. Запрос от прораба/снабженца → 2. КП с указанием наличия и сроков →3. Согласование с прорабом (техническая часть) → 4. Заказ → 5. Отгрузка с документацией в коробе → 6. Доставка до точки монтажа → 7. Монтаж + техподдержка по запросу → 8. Акт приёма-передачи


### Критичные точки для ускорения
- КП должно содержать: наличие на ближайшем складе, срок отгрузки, совместимость с проектом
- В коробе: документация + QR-код на видеоинструкцию
- Техподдержка: доступность инженера в часы монтажа (8:00–18:00)
