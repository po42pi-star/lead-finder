# Сегмент: Генподрядчики и застройщики

## 📋 Профиль сегмента

| Параметр | Значение |
|----------|----------|
| Кто это | Компании, реализующие строительные проекты «под ключ»: жилые комплексы, ТЦ, офисные центры, промышленные объекты |
| Типичный размер | 50–500+ человек, оборот 500 млн – 10+ млрд ₽/год |
| ЛПР | Руководитель проекта, директор по закупкам, технический директор, ГИП |
| Процесс закупки | Тендер/запрос → КП → согласование с тех. отделом и закупками → договор → поэтапные поставки → сдача объекта |
| Цикл сделки | 1–6 месяцев (длинный, зависит от стадии проекта) |
| Ключевой драйвер | Соблюдение графика строительства, прохождение госэкспертизы, контроль бюджета |

## 🎯 Боли и потребности (специфичные для сегмента)

### Операционные боли
| Боль | Проявление | Почему важно для генподрядчиков |
|------|-----------|-------------------------------|
| Срыв поставок оборудования | Вентиляция не приехала к этапу монтажа | Простой смежных бригад = сдвиг всего графика строительства = штрафы от заказчика |
| Несоответствие оборудования проекту | Поставка не проходит технадзор или экспертизу | Переделка проекта или замена оборудования = задержка сдачи объекта |
| Отсутствие комплексного решения | Нужно собирать вентиляцию, автоматику, монтаж у разных поставщиков | Риск «размытой» ответственности, сложности координации, увеличение сроков |
| Сложная логистика на стройплощадку | Крупногабаритное оборудование не разгружается в стеснённых условиях | Простой крана/бригады = дополнительные затраты |

### Коммерческие боли
| Боль | Проявление | Почему важно |
|------|-----------|-------------|
| Непредсказуемость бюджета | Цены меняются между тендером и закупкой | Сложно держать маржу проекта, риск убытков |
| Жёсткие условия оплаты | Заказчик платит поэтапно, а поставщики требуют предоплату | Давление на оборотные средства, кассовые разрывы |
| Отсутствие единой гарантии | Разные поставщики = разные гарантийные условия | Сложности при предъявлении претензий, риск «перекладывания» ответственности |

### Технические и административные боли
| Боль | Проявление | Почему важно |
|------|-----------|-------------|
| Неполный пакет документации | Нет сертификатов, протоколов, паспортов в нужном формате | Задержка согласования с технадзором, риск остановки работ |
| Оборудование не проходит экспертизу | Нет требуемых ГОСТ/ТР ТС, пожарных сертификатов | Невозможность сдачи объекта, штрафы, репутационные риски |
| Отсутствие техподдержки на объекте | При монтаже возникают вопросы, нет оперативного ответа | Простой бригады, ошибки в установке, переделки |

## 💬 Язык коммуникации: что говорить / что не говорить

### ✅ Говорить (триггеры доверия)
| Фраза | Почему работает для генподрядчиков |
|-------|-----------------------------------|
| «Комплексное решение «под ключ»: оборудование + автоматика + ПНР» | Закрывает боль координации множества поставщиков |
| «Полный пакет документов для экспертизы: ГОСТ, ТР ТС, протоколы» | Снимает риск задержки согласования |
| «Поэтапная отгрузка под график строительства» | Синхронизирует поставки с этапами объекта |
| «Единая точка ответственности за весь контур вентиляции» | Упрощает претензионную работу, снижает риски |
| «Гарантия 24 месяца на всё оборудование и работы» | Фиксирует обязательства, упрощает сдачу объекта |
| «Персональный менеджер проекта на весь цикл» | Предсказуемость коммуникации, быстрый ответ на вопросы |

### ❌ Не говорить (триггеры отторжения)
| Фраза | Почему отталкивает генподрядчиков |
|-------|----------------------------------|
| «Только оборудование, монтаж — ваша зона» | Не закрывает потребность в комплексности |
| «Документация по запросу» | Создаёт риски задержки согласования |
| «Срок поставки 45 дней без возможности ускорения» | Не вписывается в жёсткий график строительства |
| «Цена фиксирована только на 7 дней» | Не совместимо с длительным циклом согласования контракта |
| «Гарантия только на заводской брак» | Не покрывает риски монтажа и эксплуатации на объекте |

## ❓ Специфичные квалификационные вопросы (не из общего банка)

> Эти вопросы уникальны для сегмента и не дублируют `sales_questions_bank.md`.

### Вопросы по графику и этапам объекта
1. «На какой стадии сейчас объект: проект, закупки, монтаж, сдача?»
2. «Есть ли «критический путь» в графике, где задержка вентиляции остановит смежные работы?»
3. «Как синхронизированы поставки оборудования с этапами строительства?»
4. «Кто на объекте принимает оборудование: технадзор, заказчик, ваша служба качества?»

### Вопросы по документации и экспертизе
5. «Какой пакет документов требуется для прохождения госэкспертизы/технадзора?»
6. «Есть ли особые требования по сертификации оборудования (пожарная, экологическая)?»
7. «Как проходит согласование замены позиции, если исходная не подошла?»
8. «Кто финально подписывает акт приёма-передачи оборудования?»

### Вопросы по бюджету и процессу закупок
9. «Работаете по фиксированной смете или с возможностью корректировки?»

11. «Есть ли требования к банковской гарантии или отсрочке платежа?»

## ⚠️ Типичные возражения генподрядчиков + контекстная отработка

> Формат: возражение → ссылка на универсальную стратегию → специфичный акцент для сегмента.

### Возражение: «Цена выше, чем в тендере / у конкурентов»
- **Ссылка:** `sales_objections.md` #price_TCO
- **Контекст для генподрядчиков:** Для них «цена» — это не только закупка, но и риски срыва графика, экспертизы, гарантий. Перефразируйте: «Понимаю фокус на бюджете. Давайте сравним не только цену оборудования, но и стоимость рисков: наша поставка включает полный пакет документов для экспертизы и гарантию прохождения. Дешёвый аналог может задержать сдачу объекта на 2 недели = Х млн рублей убытка. Готовы рассмотреть расчёт рисков?»

### Возражение: «Нужно комплексное решение, а не только оборудование»
- **Ссылка:** `sales_objections.md` #turnkey_offer
- **Контекст:** Предложите не просто оборудование, а «контур под ключ» с единой ответственностью. «Закрываем весь контур вентиляции: оборудование + автоматика + пусконаладка + документация. Единый договор, одна точка ответственности, единая гарантия. Это снимает риски координации множества поставщиков. Подготовить комплексное КП?»

### Возражение: «Сроки поставки не вписываются в график строительства»
- **Ссылка:** `sales_objections.md` #timeline_accelerate
- **Контекст:** Предложите поэтапную отгрузку под критический путь монтажа. «Можем разбить поставку на этапы: первая партия — через 7 дней под критический узел, остальное — поэтапно под ваш график. Это закроет риски простоя смежных бригад. Согласовать детальный график отгрузки?»

### Возражение: «Нет уверенности в прохождении экспертизы»
- **Ссылка:** `sales_objections.md` #docs_cert
- **Контекст:** Акцент на «полный пакет с ЭЦП» и опыт сдачи объектов. «Вся документация: ГОСТ, ТР ТС, пожарные сертификаты, протоколы — в электронном виде с ЭЦП. Плюс опыт сдачи 50+ объектов с госэкспертизой. Готовы предоставить референсы и образцы документов. Это закроет вопросы технадзора?»

### Закрытие на поэтапную отгрузку под график
- **Ссылка:** `sales_closing.md` #phased_delivery
- **Адаптация:** «Чтобы синхронизировать поставки с вашим графиком, предлагаю разбить отгрузку на этапы: первая партия — через 7 дней под критический узел, остальное — по мере готовности фронта работ. Это исключит простой бригад. Утвердить график?»

### Закрытие на включение в проектную документацию
- **Ссылка:** `sales_closing.md` #include_in_spec
- **Адаптация:** «Чтобы наше оборудование было учтено в рабочей документации, давайте подготовим спецификации с нашими параметрами и пакет документов для экспертизы. Инженер сделает это за 2 дня. Это не обязывает к закупке, но упростит согласование с заказчиком позже. Пришлю черновик на проверку?»

### Закрытие на персонального менеджера проекта
- **Ссылка:** `sales_closing.md` #dedicated_manager
- **Адаптация:** «Чтобы коммуникация была предсказуемой, закрепляю за вашим объектом персонального менеджера: он координирует поставки, документацию, техподдержку. Один контакт на весь цикл. Это упрощает решение вопросов. Включить в договор?»

## 📄 Документация и процесс: что требуют генподрядчики

### Обязательный пакет документов
| Документ | Зачем генподрядчику | Формат предоставления |
|----------|---------------------|----------------------|
| Сертификаты ГОСТ/ТР ТС | Для прохождения госэкспертизы и технадзора | Электронно с ЭЦП + заверенные копии по запросу |
| Пожарные сертификаты и протоколы | Для сдачи раздела ПБ | Электронно с ЭЦП, реестр номеров |
| Паспорта изделий и руководства по эксплуатации | Для ввода в эксплуатацию и передачи заказчику | В каждом коробе + электронный архив |
| Исполнительные схемы и узлы | Для согласования с проектом | PDF/DWG + 3D-модели по запросу |
| Акты заводских испытаний | Для подтверждения качества | Электронно с ЭЦП, по запросу — оригиналы |

### Процесс взаимодействия (типичный)

1. Тендер/запрос от закупщиков → 2. КП с комплексным решением и пакетом документов → 3. Согласование с тех. отделом и ГИПом → 4. Участие в тендере / прямые переговоры → 5. Договор с поэтапными условиями → 6. Поэтапная отгрузка под график объекта → 7. Шеф-монтаж / ПНР (опция) → 8. Комплект документов для сдачи объекта → 9. Акт приёма-передачи, гарантия


### Критичные точки для ускорения
- КП должно содержать: разбивку по этапам, пакет документов для экспертизы, референсы по похожим объектам
- Персональный менеджер: один контакт на весь цикл, доступность 8:00–20:00
- Документация: готовность пакета «под экспертизу» до отгрузки, а не после
