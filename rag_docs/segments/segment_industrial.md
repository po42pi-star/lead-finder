# Сегмент: Промышленные предприятия

## 📋 Профиль сегмента

| Параметр | Значение |
|----------|----------|
| Кто это | Производственные предприятия: металлургия, химия, нефтегаз, машиностроение, пищевая промышленность, энергетика |
| Типичный размер | 100–5000+ сотрудников, оборот 500 млн – 100+ млрд ₽/год |
| ЛПР | Главный инженер, начальник производства, руководитель отдела главного механика/энергетика, директор по закупкам, технический директор |
| Процесс закупки | Технический запрос → расчёт/подбор → согласование с тех. службами → тендер/прямой контракт → поставка → ПНР → эксплуатация |
| Цикл сделки | 1–6 месяцев (зависит от сложности, бюджета, процедуры закупок) |
| Ключевой драйвер | Надёжность оборудования, минимизация простоев, соответствие техрегламентам и ГОСТ, постпродажная поддержка |

## 🎯 Боли и потребности (специфичные для сегмента)

### Операционные боли
| Боль | Проявление | Почему важно для промышленных предприятий |
|------|-----------|------------------------------------------|
| Простой производства из-за отказа оборудования | Вентилятор/клапан вышел из строя → остановка линии → убытки | Минута простоя = тысячи/миллионы рублей убытка; приоритет — надёжность, а не цена |
| Несоответствие оборудования условиям среды | Оборудование не выдерживает температуру, агрессивность, запылённость | Риск аварии, нарушения технологии, штрафов от надзорных органов |
| Отсутствие запчастей в наличии | При поломке ждать поставку 2–4 недели | Простой линии, срыв плана выпуска, контрактные штрафы |
| Сложность интеграции в существующий техпроцесс | Оборудование не стыкуется с текущей автоматикой или компоновкой | Дополнительные затраты на доработку, риск ошибок при монтаже |

### Технические и нормативные боли
| Боль | Проявление | Почему важно |
|------|-----------|-------------|
| Отсутствие требуемых сертификатов | Нет ГОСТ, ТР ТС, взрывозащиты, пожарных протоколов | Невозможность ввода в эксплуатацию, штрафы, приостановка производства |
| Нет технической документации на русском/в нужном формате | Паспорта, схемы, инструкции не соответствуют требованиям предприятия | Сложности с приёмкой, обучением персонала, ТО |
| Оборудование не проходит внутренний техаудит | Служба главного инженера не допускает к монтажу | Задержка проекта, пересмотр спецификации, репутационные риски |

### Коммерческие и процессуальные боли
| Боль | Проявление | Почему важно |
|------|-----------|-------------|
| Жёсткие процедуры закупок | Только тендер, только аккредитованные поставщики, сложные условия | Длинный цикл согласования, риск проигрыша по цене, а не по качеству |
| Непредсказуемость бюджета | Цены на металл/комплектующие меняются, бюджет фиксируется на год | Сложности с планированием, риск выхода за лимит |
| Отсутствие единой гарантии и сервиса | Разные поставщики = разные условия, «перекладывание» ответственности | Сложности при предъявлении претензий, риск простоя при ремонте |

## 💬 Язык коммуникации: что говорить / что не говорить

### ✅ Говорить (триггеры доверия)
| Фраза | Почему работает для промышленных предприятий |
|-------|---------------------------------------------|
| «Оборудование сертифицировано по ГОСТ/ТР ТС, есть протоколы испытаний» | Закрывает нормативные требования, снижает риск отказа в приёмке |
| «Ресурс работы: 10+ лет при соблюдении регламента ТО» | Соответствует приоритету надёжности и долгосрочной эксплуатации |
| «ЗИП на складе, отгрузка запчастей за 1–3 дня» | Снижает риск длительного простоя при ремонте |
| «Взрывозащита 1Ех, жаропрочные стали, коррозионностойкое исполнение» | Решает задачи работы в агрессивных/опасных средах |
| «Инженерный аудит и подбор под ваш техпроцесс — бесплатно» | Демонстрирует экспертность, снижает риск ошибки в спецификации |
| «Сервисный контракт: реакция до 4 часов, гарантия на работы» | Фиксирует обязательства, упрощает планирование ТО |

### ❌ Не говорить (триггеры отторжения)
| Фраза | Почему отталкивает промышленные предприятия |
|-------|--------------------------------------------|
| «Скидка 20% при заказе сегодня» | Не релевантно: решение принимается коллегиально, по процедуре, не импульсно |
| «Модель новая, опыта эксплуатации мало» | Противоречит приоритету надёжности и проверенных решений |
| «Документация будет после отгрузки» | Создаёт риски задержки приёмки и ввода в эксплуатацию |
| «Монтаж — ваша зона ответственности» | Не закрывает потребность в комплексной поддержке на объекте |
| «Срок поставки 45 дней без возможности ускорения» | Не вписывается в графики ремонтов и модернизации |

4. «Какое давление/разрежение в сети, есть ли пульсации или гидравлические удары?»

## ⚠️ Типичные возражения промышленных предприятий + контекстная отработка

> Формат: возражение → ссылка на универсальную стратегию → специфичный акцент для сегмента.

### Возражение: «Цена выше, чем у аналогов»
- **Ссылка:** `sales_objections.md` #price_TCO
- **Контекст для промышленных предприятий:** Для них «цена» — это не закупка, а совокупная стоимость владения с учётом простоев, ремонтов, штрафов. Перефразируйте: «Понимаю фокус на бюджете. Давайте сравним не только цену оборудования, но и стоимость рисков: наше оборудование имеет ресурс 10+ лет, ЗИП на складе, сервис с реакцией до 4 часов. Простой линии 1 день = Х млн рублей. Наша наценка = Y рублей. Готовы рассмотреть расчёт совокупной стоимости?»

### Возражение: «Нет опыта работы в наших условиях (температура/агрессия/взрывоопасность)»
- **Ссылка:** `sales_objections.md` #pilot_offer
- **Контекст:** Предложите не «поверьте на слово», а «проверьте на практике». «Готовы поставить 1 единицу на тестовый участок с мониторингом вибрации, температуры, расхода. Инженер подготовит отчёт по результатам. Если устроит — масштабируем на всю линию. Согласовать параметры пилота?»

### Возражение: «Требуется специсполнение (взрывозащита, жаропрочность, коррозионностойкость)»
- **Ссылка:** `sales_objections.md` #custom_execution
- **Контекст:** Акцент на «инженерный расчёт под параметры» и «сертификацию». «Изготовим исполнение с маркировкой 1Ех / из стали 12Х18Н10Т / с системой охлаждения подшипников. Инженер подготовит расчёт под ваши параметры и пакет сертификатов. Это закроет вопросы техаудита. Отправить ТЗ на проработку?»

### Возражение: «Сложности с интеграцией в существующую автоматику»
- **Ссылка:** `sales_objections.md` #integration_support
- **Контекст:** Предложите не «совместимо», а «проверим на стенде». «Наши контроллеры поддерживают открытые протоколы. Готовы проверить связь с вашей SCADA на тестовом стенде перед заказом. Инженер подготовит схему подключения. Это исключит риски на монтаже. Согласовать тест?»

## 📄 Документация и процесс: что требуют промышленные предприятия

### Обязательный пакет документов
| Документ | Зачем промышленному предприятию | Формат предоставления |
|----------|---------------------------------|----------------------|
| Сертификаты ГОСТ/ТР ТС, пожарные, взрывозащиты | Для допуска к эксплуатации, прохождения надзорных проверок | Электронно с ЭЦП + реестр номеров для проверки в органах |
| Паспорта изделий с точными характеристиками и ресурсом | Для спецификации, регламента ТО, отчётности | В каждом коробе + электронный архив с поиском по артикулу |
| Протоколы заводских испытаний | Для подтверждения соответствия заявленным параметрам | Электронно с ЭЦП, по запросу — оригиналы |
| Схемы подключения, интеграции, алгоритмы работы | Для стыковки с существующей автоматикой и техпроцессом | PDF/DWG + исходные файлы по запросу |
| Инструкции по эксплуатации и ТО на русском | Для обучения персонала, соблюдения регламентов | Печатные + электронные с возможностью обновления |

### Процесс взаимодействия (типичный)

1. Технический запрос от службы главного инженера → 2. Закрепление инженера-консультанта, аудит параметров → 3. Подготовка расчётов, спецификации, пакета документов → 4. Согласование с техсоветом/закупочным комитетом → 5. Участие в тендере / прямой контракт → 6. Поставка с полным пакетом документации → 7. Шеф-монтаж / ПНР (опция) → 8. Ввод в эксплуатацию, акт приёма-передачи → 9. Сервисное сопровождение по контракту


### Критичные точки для ускорения
- Ответ на технический запрос: не более 24 часов
- Расчёты и спецификации: подготовка за 1–2 рабочих дня
- Документация: готовность пакета «под техаудит» до отгрузки
- Сервис: доступность инженера 24/7 для критичных объектов
